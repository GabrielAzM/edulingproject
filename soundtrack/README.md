# Trilha sonora

Coloque nesta pasta os arquivos de áudio com um destes formatos:

- `.mp3`
- `.ogg`
- `.wav`
- `.m4a`

Nomes esperados para cada tela:

- `index` para a tela inicial
- `memoria` para o jogo da memória
- `domino` para o jogo de dominó
- `uno` para o jogo de UNO
- `cambleplay` para o tabuleiro

Exemplos válidos:

- `index.mp3`
- `memoria.ogg`
- `domino.wav`
- `uno.m4a`
- `cambleplay.mp3`

Comportamento configurado no projeto:

- a trilha troca automaticamente ao mudar de tela
- cada faixa roda em loop
- o navegador inicia a reprodução após a primeira interação do usuário com a página
- o botão `Som ligado` no cabeçalho permite ligar e desligar a trilha a qualquer momento
